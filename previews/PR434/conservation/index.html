Constrained Hilbert spaces and conserved quantum numbers

Conservation laws let you work in a small part of an exponentially large Hilbert space. This page shows how a constraint selects basis states and groups them into sectors of fixed quantum numbers, lists the available constraints, and ends with worked examples where the full space would be far too large to build.

Constraints and sectors

A constraint selects basis states, and can split them into sectors labelled by quantum numbers. It is given when building a space, either to hilbert_space or as the constraint keyword of tensor_product, and constrain_space applies one to an existing space:

using FermionicHilbertSpaces@fermions fN = sum(f[k]'f[k] for k in 1:3)H = hilbert_space(f, 1:3, N)
8-dimensional SectorHilbertSpace
Parent: f[1, 2, 3]
Sectors: [0 (1-dim), 1 (3-dim), 2 (3-dim), 3 (1-dim)]

The sector labels of a space are its quantum numbers. A sector is a space of its own, and an operator that conserves the quantity can be represented directly on it:

hopping = sum(f[k]'f[k+1] + hc for k in 1:2)representation(hopping, sector(2, H))
3×3 SparseArrays.SparseMatrixCSC{Int64, Int64} with 4 stored entries:
 ⋅  1  ⋅
 1  ⋅  1
 ⋅  1  ⋅

Writing a constraint

A constraint is quantity => f => g => ... => allowed, where everything after quantity is optional:

  • quantity is a diagonal operator, such as N, or a function of the basis state.
  • f, g, … are functions applied to the value of the quantity in turn.
  • allowed is a single value or a collection of values.

With v the value after the functions, the end of the constraint decides what it does:

the constraint ends inexamplekeeps the states wherelabels sectors by
a value aN => 2v == anone
a collection cN => 0:2v ∈ cv
a quantity or function giving true or falseN => isoddv is truenone
a quantity or function giving anything elseN, N => parityalwaysv

A state where a function returns missing is discarded. To allow a single tuple or vector, wrap it, as in => [(0, 1)].

ParityConservation is a shorthand for N => (v -> (-1)^v) => [-1, 1] with N the total particle number, which also counts bosons.

Several constraints go in a tuple or a vector, and a sector label then has one entry per quantity. A spin chain split into sectors of total $S^z$, and the Rydberg blockade, which forbids neighbouring excitations:

@spins S 1 // 2Sz = sum(S[i][:z] for i in 1:6)Hspin = hilbert_space(S, 1:6, Sz)up(i) = S[i][:z] + 1 // 2blockade = [up(i) * up(i + 1) => 0 for i in 1:9]Hpxp = hilbert_space(S, 1:10, blockade)quantumnumbers(Hspin), dim(Hpxp)
(Rational{Int64}[-3, -2, -1, 0, 1, 2, 3], 144)

The values of an operator are exact: labels are integers when every term takes integer values, and rationals otherwise. Coefficients must be integers or rationals, while the values of operators such as b'b are rounded to exact fractions. Complex values are not supported; for a $\mathbb{Z}_N$ charge with values $\omega^q$, write Q as a sum of operators with the integer values $q$ and constrain Q => (v -> mod(v, N)).

A function of the basis state works the same way:

nup(state) = count(s -> s.m > 0, state.states)dim(hilbert_space(S, 1:6, nup => 2)), dim(hilbert_space(S, 1:6, s -> nup(s) <= 1))
(15, 7)

Applied to a space with sectors, a constraint written this way keeps those sectors, and its own labels follow theirs.

How a constrained space is built

The states are built one factor at a time, as a tree. Each term of an operator is assigned to the factors it acts on, so after each factor the value so far is known, along with the range that the remaining factors can still add. A branch that cannot reach an allowed value is skipped. For a particle number, a magnetization or a blockade, every branch that is kept leads to a kept state, so the cost grows with the size of the result rather than the full space. A term that acts on several factors is tabulated on their product, which may have at most 4096 states.

A function of the basis state cannot be split this way, so it is evaluated on every state of the full space, which must be small enough to build. constrain_space on a space that is already constrained also checks its states one by one.

Lower-level constraints

NumberConservation

Conserves the particle number, or a weighted sum of the particle numbers of selected spaces. The allowed total is one value or a collection; leaving it out keeps all sectors.

@boson bHf = hilbert_space(f, 1:3)Hb = hilbert_space(b, 10)# fermions in Hf minus bosons in Hb is 0 or 1imbalance = NumberConservation(0:1, [Hf, Hb], [1, -1])tensor_product(Hf, Hb; constraint = imbalance)
15-dimensional SectorHilbertSpace
Parent: ProductSpace(80-dim, 2 factors)
Sectors: [0 (8-dim), 1 (7-dim)]

ParityConservation

Conserves the parity of the particle number, 1 for even and -1 for odd states; without arguments it keeps both sectors.

Products of constraints

Multiplying constraints imposes all of them, and the quantum number of a sector has one entry per factor. Here each pair of modes holds at most one fermion, and there are two fermions in total:

pairs = [hilbert_space(f, 2k-1:2k) for k in 1:3]pair_constraint = prod(NumberConservation(0:1, Hk) for Hk in pairs) * NumberConservation(2)tensor_product(pairs; constraint = pair_constraint)

Parent: f[1, 2, 3, 4, 5, 6]
Sectors: [[0, 1, 1, 2] (4-dim), [1, 0, 1, 2] (4-dim), [1, 1, 0, 2] (4-dim)]

AdditiveConstraint

Conserves a sum of contributions from the factors of a tensor product, given by maps applied to the state of each factor. It works for any space, also one without symbolic operators:

FilterConstraint

Keeps the states for which a function returns true. With maps and spaces, the function receives the value of each map on the state of its space. Here the particle numbers of two bosonic modes must be sorted:

BranchConstraint

Builds the states one factor at a time and calls f(partial_state, depth, spaces) after each factor is assigned. Returning false discards every state that starts this way, so a sector much smaller than the full space is found without enumerating it. Here no two neighbouring modes are both occupied:

no_neighbours = BranchConstraint((p, depth, spaces) -> depth == 1 || particle_number(p[depth]) + particle_number(p[depth-1]) < 2)dim(hilbert_space(f, 1:20, no_neighbours))
17711

Examples

Spinful fermions

The package does not special-case spinful fermions: spin is an extra label. If the numbers of spin up and spin down fermions are separately conserved, the space divides into sectors labelled by both numbers:

using FermionicHilbertSpaces@fermions flabels = [(i, σ) for i in 1:4 for σ in (:↑, :↓)]Nup = sum(f[i, :↑]'f[i, :↑] for i in 1:4)Ndn = sum(f[i, :↓]'f[i, :↓] for i in 1:4)H = hilbert_space(f, labels, (Nup, Ndn))
256-dimensional SectorHilbertSpace
Parent: f[(1, :↑), (1, :↓), ..., (4, :↑), (4, :↓)]
Sectors: 25 total [[0, 0] (1-dim), ..., [4, 4] (1-dim)]

The sector with two spin up and no spin down fermions can be picked out of this space, or built directly, which is cheaper since it never enumerates the full space:

two_up_none_down = (Nup => 2, Ndn => 0)@assert Set(basisstates(sector((2, 0), H))) == Set(basisstates(hilbert_space(f, labels, two_up_none_down)))sector((2, 0), H)
6-dimensional ConstrainedSpace
Parent: f[(1, :↑), (1, :↓), ..., (4, :↑), (4, :↓)]

A state found on a sector, such as the ground state of the hopping there, is placed in the full space by embed, and indices gives the positions of the sector's states in it:

using LinearAlgebraH20 = sector((2, 0), H)hopping = sum(f[i, σ]'f[i+1, σ] + hc for i in 1:3 for σ in (:↑, :↓))ψ = eigvecs(Hermitian(representation(hopping, H20, Matrix)))[:, 1]@assert embed(ψ, H20 => H)[indices((2, 0), H)] ≈ ψindices((2, 0), H)

Hubbard model

The Hubbard model

\[H = -t \sum_{i,\sigma} (c_{i,\sigma}^\dagger c_{i+1,\sigma} + \mathrm{h.c}) + U \sum_i n_{i,↑} n_{i,↓}\]

conserves the number of spin up and spin down fermions separately. On 20 sites the full space has dimension $4^{20} \approx 10^{12}$, but the sector with two spin up fermions and one spin down fermion is small, and is generated directly:

using FermionicHilbertSpacesfunction hubbard_hamiltonian(c, N, t, U)    spins = (:↑,:↓)    sum(-t * c[i,σ]' * c[i+1,σ] + hc for σ in spins for i in 1:N-1) +    sum(U * c[i,:↑]'c[i,:↑] * c[i,:↓]'c[i,:↓] for i in 1:N)end@fermions fN = 20Hup = hilbert_space(f, [(i, :↑) for i in 1:N], NumberConservation(2))Hdn = hilbert_space(f, [(i, :↓) for i in 1:N], NumberConservation(1))H = tensor_product(Hup, Hdn)ham = representation(hubbard_hamiltonian(f, N, 1.0, 4.0), H);size(ham)
(3800, 3800)
No double occupation

For strong interactions, double occupation can be forbidden by constraining the number of doubly occupied sites to zero. The hamiltonian maps some states of this subspace outside it, and projection = true drops those terms:

D = sum(f[k, :↑]'f[k, :↑] * f[k, :↓]'f[k, :↓] for k in 1:N)H_ndo = constrain_space(H, D => 0)ham_ndo = representation(hubbard_hamiltonian(f, N, 1, 0), H_ndo; projection = true);size(ham_ndo)
(3420, 3420)

Tavis–Cummings model

$N$ spin-1/2 emitters coupled to a cavity mode,

\[H = \omega a^\dagger a + \omega_0 \sum_i S^z_i + g \sum_i \left(a^\dagger S^-_i + a S^+_i\right),\]

conserve the number of excitations, the boson number plus $\sum_i (S^z_i + 1/2)$:

using FermionicHilbertSpacesN = 3nmax = 4@spins S 1//2@boson aspaces = [hilbert_space(a, nmax + 1); [hilbert_space(S[i]) for i in 1:N]]excitations = a'a + sum(S[i][:z] + 1//2 for i in 1:N)H = tensor_product(spaces; constraint = excitations)
40-dimensional SectorHilbertSpace
Parent: ProductSpace(40-dim, 4 factors)
Sectors: 8 total [0//1 (1-dim), ..., 7//1 (1-dim)]

The Hamiltonian is block diagonal in these sectors, one per excitation number.

Fractionalized Hilbert space of the t-Jz model

The $t-J_z$ model

\[H = -t \sum_{i,\sigma} (c_{i,\sigma}^\dagger c_{i+1,\sigma} + \mathrm{h.c}) + J_z \sum_{i} S^z_i S^z_{i+1},\]

with $S^z_i = n_{i,↑} - n_{i,↓}$ and no double occupation, has a Hilbert space that splits into exponentially many dynamically disconnected sectors[1]. Each sector is labelled by a spin pattern such as ↑↑↓↑↓: its states have the spins of the occupied sites in exactly that order, with holes in between. A BranchConstraint builds one such sector without the full space:

import FermionicHilbertSpaces: particle_numberfunction tjz(c, N, t, Jz)    spins = (:↑,:↓)    Sz(i) = c[i,:↑]'c[i,:↑] - c[i,:↓]'c[i,:↓]    -t*sum(c[i,σ]'c[i+1,σ] + hc for σ in spins for i in 1:N-1) + Jz*sum(Sz(i)Sz(i+1) for i in 1:N-1)end# partials holds the fock numbers of the 2N modes, of which the first `depth` are assignedfunction valid_state(partials, depth, spaces, expected_order)    exc_count = 0    prev_site = 0    for n in 1:depth        if particle_number(partials[n]) == 1            exc_count += 1            site, spin = only(spaces[n].modes).label            exc_count > length(expected_order) && return false            site == prev_site && return false # the spaces are ordered by site            prev_site = site            expected_order[exc_count] == spin || return false        end    end    depth == length(spaces) && return exc_count == length(expected_order)    return trueendspin_order_constraint(order) = BranchConstraint((p, d, s) -> valid_state(p, d, s, order))N = 16labels = [(i, s) for i in 1:N for s in (:↑,:↓)]Hfrac = hilbert_space(f, labels, spin_order_constraint([:↑, :↑, :↓, :↑, :↓]))ham = representation(tjz(f, N, 1, 1/4), Hfrac; projection = true);dim(Hfrac)
4368

Total spin and SU(N) multiplets

A multiplet of total spin $S$ has exactly one highest-weight state, the state with $S^z_\mathrm{tot} = S$ that $S^+_\mathrm{tot}$ annihilates; lowering it with $S^-_\mathrm{tot}$ gives the rest of the multiplet. On a space split into $S^z_\mathrm{tot}$ sectors, highest_weight_states returns these states, one column per multiplet, keyed by $S$. This gives the lowest energy for each total spin of a Heisenberg ring:

using FermionicHilbertSpaces, LinearAlgebrausing FermionicHilbertSpaces: highest_weight_states, multiplets@spins S 1 // 2N = 6ham = sum(S[k][:]'S[mod1(k + 1, N)][:] for k in 1:N)Sz = sum(S[k][:z] for k in 1:N)Splus = sum(S[k][:+] for k in 1:N)H = hilbert_space(S, 1:N, Sz => 0:(N // 2))energies(op, V, qn, H) = eigvals(Hermitian(V' * representation(op, sector(qn, H), Matrix) * V))[s => minimum(energies(ham, V, s, H)) for (s, V) in highest_weight_states(H, Splus)]

Hubbard ring: spin and pseudospin

At half filling, the particle-hole-symmetric Hubbard ring with an even number of sites has two commuting SU(2) symmetries: spin, raised by $S^+ = \sum_i c^\dagger_{i↑} c_{i↓}$, and η-pairing pseudospin, raised by $η^+ = \sum_i (-1)^i c^\dagger_{i↑} c^\dagger_{i↓}$. Since $η^+$ changes the particle number, the space is the full Fock space split by (Nup, Ndn). The key [Nup, Ndn] then holds the multiplets with $S = (N_↑ - N_↓)/2$ and $η = (N_↑ + N_↓ - L)/2$, and the lowest energy for each $(S, η)$ is

@fermions fL = 4Nup = sum(f[i, :↑]'f[i, :↑] for i in 1:L)Ndn = sum(f[i, :↓]'f[i, :↓] for i in 1:L)H = hilbert_space(f, [(i, σ) for i in 1:L for σ in (:↑, :↓)], (Nup, Ndn))hub = sum(-f[i, σ]'f[mod1(i + 1, L), σ] + hc for i in 1:L for σ in (:↑, :↓)) +    4 * sum((f[i, :↑]'f[i, :↑] - 1 // 2) * (f[i, :↓]'f[i, :↓] - 1 // 2) for i in 1:L)Splus = sum(f[i, :↑]'f[i, :↓] for i in 1:L)etaplus = sum((-1)^i * f[i, :↑]'f[i, :↓]' for i in 1:L)@assert iszero(hub * Splus - Splus * hub) && iszero(hub * etaplus - etaplus * hub)[(S = (nup - ndn) // 2, η = (nup + ndn - L) // 2) => minimum(energies(hub, V, [nup, ndn], H)) for ((nup, ndn), V) in highest_weight_states(H, [Splus, etaplus])]

Passing only Splus gives the spin multiplets alone. The functions never see the Hamiltonian, so the check that it commutes with the raisers is up to the caller. For example, $η^+$ commutes only with the particle-hole-symmetric interaction $U (n_↑ - 1/2)(n_↓ - 1/2)$; with $U n_↑ n_↓$ its multiplets do not block-diagonalize the Hamiltonian, and nothing warns about it.

SU(3) flavour exchange

Several raisers go in a vector. Three-flavour fermions with one fermion per site have sectors labelled by the three flavour numbers, and the raisers of SU(3) are the two flavour hops. On a 3-site ring the space splits as $10 \oplus 8 \oplus 8 \oplus 1$, with keys [3, 0, 0], [2, 1, 0] (two multiplets) and [1, 1, 1]. The flavour-exchange Hamiltonian has one energy per irrep:

@fermions cL = 3n(a) = sum(c[i, a]'c[i, a] for i in 1:L)one_per_site = [sum(c[i, a]'c[i, a] for a in 1:3) => 1 for i in 1:L]H = hilbert_space(c, [(i, a) for i in 1:L for a in 1:3], (one_per_site..., n(1), n(2), n(3)))raisers = [sum(c[i, a]'c[i, a + 1] for i in 1:L) for a in 1:2]exchange = sum(c[i, a]'c[i, b] * c[mod1(i + 1, L), b]'c[mod1(i + 1, L), a] for i in 1:L for a in 1:3 for b in 1:3)[w => energies(exchange, V, w, H) for (w, V) in highest_weight_states(H, raisers)]

embed(m, Hsub => H; complement=complementary_subsystem(H, Hsub), kwargs...)

Compute the embedding of a matrix m in the basis Hsub into the basis H.

factors(H)

Split H one level down: a product space into its groups, a grouped space (such as a fermionic space) into its atoms, and an atomic space into itself.

hc

op + hc is op + op' and op - hc is op - op', for example f[1]'f[2] + hc.

hilbert_space(f, labels, [constraint]) hilbert_space(b, labels, dimension, [constraint]) hilbert_space(s, labels, [J], [constraint])

Construct the Hilbert space of the fermions f, bosons b (truncated at dimension) or spins s (spin J) with the given labels, optionally restricted by a constraint, e.g. NumberConservation(2).

hilbert_space(b::BosonSym, dimension[, constraint]) hilbert_space(b::Field{Boson}, labels, dimension[, constraint])

The truncated space of the bosonic mode b, with basis states |0⟩, …, |dimension-1⟩, so the maximal occupation is dimension - 1.

indices(Hsub, H) indices(qn, H)

Return the basis-state indices in H belonging to a given sector, specified either by a sector Hilbert space Hsub or by a quantum number qn, given as for sector.

quantumnumbers(H)

Return the quantum-number labels that define the sectors of H, sorted in increasing order when they can be compared.

representation(op_or_state, space::AbstractHilbertSpace, [repr]; kwargs...) representation(op, Axes(Hout, Hin), [repr]; kwargs...) representation(state_expression; kwargs...)

Return a concrete representation of op_or_state in Hilbert space space.

sector(qn, H)

Return the sector of H corresponding to quantum number qn, for example a particle number for NumberConservation or 1 (even) / -1 (odd) for ParityConservation.

sectors(H)

Return all sectors of H in the same order as quantumnumbers(H).

subregion(Hs, H::AbstractHilbertSpace)

Return the subsystem of H spanned by the factors Hs, given as a space, a symbolic operator, or a list/tuple of spaces or symbolic operators (e.g. [f[1], b[2]]).

tensor_product(spaces...; constraint=NoSymmetry()) tensor_product(spaces; constraint=NoSymmetry())

Construct the composite Hilbert space from the spaces in spaces, with optional keyword argument constraint.

fragment(op, H, seeds; projection = false, depth = typemax(Int), cutoff = 0)

Return the smallest subspace of H spanned by basis states that contains seeds and is closed under op, e.g. FermionicHilbertSpaces.fragment(pxp, H, ["↓↓↓↓"]).

hilbert_space(f::Field{Fermion}, labels, ::BdG)

The space of Nambu states [f[l] for l in labels; f[l]' for l in labels].

hilbert_space(f::Field{Fermion}, labels, ::SingleParticle)

The space spanned by the states for the modes f[l], l in labels, suitable for non-interacting systems with fermion number conservation.

hilbert_space(γ::Field{Majorana}, labels, ::SingleParticle)

The space of the Majoranas γ[l], l in labels, for quadratic Majorana operators.
