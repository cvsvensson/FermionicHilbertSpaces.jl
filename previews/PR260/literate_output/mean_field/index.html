Self-consistent mean-field theory

mean_field(ham, G, Hbdg) turns an interacting operator into a quadratic one by decoupling it in a Gaussian state with Nambu correlation matrix G. Iterating this to self-consistency gives Hartree-Fock-Bogoliubov theory in a few lines. We use it on the Hubbard ring to find an antiferromagnet at repulsive and a superconductor at attractive interaction, and compare the energy with exact diagonalization.

using FermionicHilbertSpaces, LinearAlgebrausing FermionicHilbertSpaces.FreeFermions

We take a ring of L sites with spin. At μ = U/2 the model is particle-hole symmetric, so the ring is half filled.

@fermions fL = 6spins = (:↑, :↓)labels = [(i, σ) for i in 1:L for σ in spins]n(i, σ) = f[i, σ]' * f[i, σ]hopping = sum(-f[i, σ]' * f[mod1(i + 1, L), σ] + hc for i in 1:L, σ in spins)hubbard(U) = hopping + U * sum(n(i, :↑) * n(i, :↓) for i in 1:L) - U / 2 * sum(n(i, σ) for i in 1:L, σ in spins);

The decoupled Hamiltonian contains the Hartree, Fock and pairing terms and is quadratic, so its BdG ground state gives the next G.

Hbdg = hilbert_space(f, labels, BdG())ground_state_correlations(op, Hbdg) = correlation_matrix(eigen(representation(op, Hbdg, :dense), BdGEigen()));function self_consistent(ham, G, Hbdg; tol = 1.0e-8, maxiter = 1000)    for _ in 1:maxiter        Gnew = ground_state_correlations(mean_field(ham, G, Hbdg), Hbdg)        norm(Gnew - G) < tol && return Gnew        G = Gnew    end    error("The mean-field iteration did not converge in $maxiter steps.")end;

The iteration keeps every symmetry of the initial state, so a symmetry-broken solution needs a seed that breaks it. For repulsive U we start from the ground state of the hopping in a staggered magnetic field, and for attractive U from uniform on-site pairing. The seed is not part of the mean-field Hamiltonian, so what remains is the spontaneous order. The mean-field state is Gaussian, so the energy of the interacting Hamiltonian in it follows from Wick's theorem, and the decoupled Hamiltonian has the same energy.

staggered = sum((-1)^i * (n(i, :↑) - n(i, :↓)) for i in 1:L)pairing = sum(f[i, :↑]' * f[i, :↓]' + hc for i in 1:L)G = self_consistent(hubbard(6), ground_state_correlations(hopping + staggered, Hbdg), Hbdg)@assert expectation(mean_field(hubbard(6), G, Hbdg), G, Hbdg) ≈ expectation(hubbard(6), G, Hbdg)

A variational energy lies above the exact ground-state energy, which we get by diagonalizing the half-filled sector with equally many up and down electrons. We sweep U from strong coupling towards zero, starting each point from the previous solution so that the iteration follows the ordered branch for as long as it exists, and compare with exact diagonalization. Energies are measured from the Fermi sea of the hopping, the mean-field solution without order.

Hup = hilbert_space(f, [(i, :↑) for i in 1:L])Hdn = hilbert_space(f, [(i, :↓) for i in 1:L])Hsector = tensor_product(Hup, Hdn; constraint = NumberConservation(L ÷ 2, Hup) * NumberConservation(L ÷ 2, Hdn))G_fermi_sea = ground_state_correlations(hopping, Hbdg)function sweep(Us, seed, order_parameter)    G = ground_state_correlations(hopping + seed, Hbdg)    return map(Us) do U        ham = hubbard(U)        G = self_consistent(ham, G, Hbdg)        E_sea = real(expectation(ham, G_fermi_sea, Hbdg))        E_exact = eigmin(Hermitian(representation(ham, Hsector, :dense)))        E_mf = real(expectation(ham, G, Hbdg))        @assert E_mf > E_exact        (order = order_parameter(G), E_mf = E_mf - E_sea, E_exact = E_exact - E_sea)    endend;Us = 8:-0.5:0afm = sweep(Us, staggered, G -> abs(real(expectation(staggered, G, Hbdg))) / 2L)sc = sweep(-Us, pairing, G -> abs(expectation(f[1, :↓] * f[1, :↑], G, Hbdg)));using PlotsUall, both = [-Us; reverse(Us)], [sc; reverse(afm)]p1 = plot(-Us, getfield.(sc, :order); label = "pairing |⟨c↓c↑⟩|", ylabel = "order parameter", legend = :top)plot!(p1, Us, getfield.(afm, :order); label = "staggered moment")p2 = plot(Uall, getfield.(both, :E_mf); label = "mean field", ylabel = "E − E(Fermi sea)", legend = :bottom)plot!(p2, Uall, getfield.(both, :E_exact); label = "exact")plot(p1, p2; layout = (1, 2), xlabel = "U", lw = 2, size = 0.7 .* (1100, 420), frame = :box, margins = 4Plots.mm)

Each order appears only beyond a threshold coupling and then grows towards saturation. The two sides are mirror images: at half filling, a particle-hole transformation of the down spins maps the repulsive ring onto the attractive one and turns the staggered moment into the pairing amplitude. The threshold is a finite-size effect, since the ring has a gap at the Fermi level that the interaction must overcome before ordering lowers the energy. Mean field stays above the exact energy everywhere, as a variational state must, misses the energy gain at weak coupling, and captures most of it at strong coupling.
