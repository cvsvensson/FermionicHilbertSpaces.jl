FermionicHilbertSpaces.jl

FermionicHilbertSpaces.jl turns symbolic fermion, boson and spin operators into matrices on Hilbert spaces, so you can define your own physics and never index vectors and matrices by hand. It started as a tool for tensor products and partial traces of fermions, which need care with signs[1], and now also covers bosons, spins and algebras you define yourself.

  • Operators are written and simplified with ordinary algebra, e.g. c[1]'c[2] + hc (Kitaev chain).
  • Their matrices can be built on any constrained space, not only the full Fock space (mixed fermion-spin-boson).
  • Constraints range from particle number and parity to any rule on the basis states (constrained spaces).
  • Tensor products, partial traces and embeddings take a pair of spaces, as in partial_trace(ρ, H => Hsub) (space operations).
  • Fermionic signs are handled automatically (fermionic conventions).

It is not a solver: combine it with LinearAlgebra, KrylovKit or ODE solvers for eigenstates and time evolution.

Getting started

Install with using Pkg; Pkg.add("FermionicHilbertSpaces"). Hopping between two sites conserves particle number, so we diagonalize in the one-particle sector, the subspace with exactly one particle. We then embed the ground state in the full space and trace out the second site:

using FermionicHilbertSpaces, LinearAlgebra@fermions cH = hilbert_space(c, 1:2)Hn = hilbert_space(c, 1:2, NumberConservation(1))ham = c[1]'c[2] + hc + 0.5 * c[1]'c[1]E = eigen(Hermitian(representation(ham, Hn, :dense)))ψ = embed(E.vectors[:, 1], Hn => H)partial_trace(ψ, H => hilbert_space(c, 1:1))
