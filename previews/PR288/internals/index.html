FermionicHilbertSpaces.AbstractBasisState — Type
AbstractBasisState

Supertype of basis-state types such as FockNumber, BosonicState and SpinState. A space may use any type for its states, as in GenericHilbertSpace(:A, [:a, :b]); subtyping AbstractBasisState lets strings name the states (see interpret_state) and lets constrained spaces look up states of other types (they get index 0).

FermionicHilbertSpaces.AbstractSubspace — Type
AbstractSubspace{B,P} <: AbstractHilbertSpace{B}

A space spanned by some of the basis states of parent(H)::P. A subtype implements

  • parent(H): the space that H is a subspace of. It is never an AbstractSubspace.
  • subspace_states(H): the basis states of H, in order, each appearing once.
  • subspace_index(H): an index with a state_position method for the states of H, such as default_subspace_index(constraint, parent(H), subspace_states(H)), built once by the constructor.
  • rewrap(H, newparent): the space with the same states and index as H over newparent, which has the same basis states and state_index as parent(H).

It may also implement subspace_key(H), the values compared by == and hash, which defaults to (parent(H), subspace_states(H)), and show_details(io, H), printed after the parent by show.

The states are meant to be basis states of parent(H), but this is not checked. Some spaces store other states over a FermionicSpace parent: hilbert_space(f, labels, states) with FixedNumberFockStates, FreeFermions.BdG spaces with FreeFermions.NambuStates and FreeFermions.SingleParticle spaces with FreeFermions.SingleParticleStates.

A subtype gets dim, basisstates, basisstate, state_index, ==, hash, show, add_tag and TransposedSpace. The functions that describe its modes and apply operators are forwarded to parent(H), so that matrix representations, tensor products, partial traces, subregion and constrain_space work on it.

FermionicHilbertSpaces.ProductSpaceMapper — Type
ProductSpaceMapper(source::ProductSpace, targets)

Mapper between source and the partition (or sub-collection) targets.

Fields:

  • leaves : per source factor, an Uncovered, Passthrough or Fractured leaf describing how that factor fractures.
  • factor_routes : per source factor, one PieceIndex{target, group_slot} per piece (in the factor's piece order). Drives combine.
  • target_routes : per target, one PieceIndex{factor, piece_slot} per group (in the target's group order). Drives split.
  • target_spaces : the targets themselves.

factor_routes and target_routes are the two directional views of the same piece table; they are exact inverses of each other by construction.

Base.reshape — Method
reshape(t, mappings...; repeat=false, skipmissing=false)

Reshape the array t by splitting or combining its indices according to Hilbert-space mappings. The mappings are applied left to right, each one consuming the next consecutive group of input indices. Each mapping reads input => output; see Pair arguments.

Mapping forms

H => (H1, H2, ...)   split one index into several(H1, H2, ...) => H   combine several consecutive indices into one(H1, H2, ...) => (K1, K2, ...)  repartition several indices into severalH => H               leave one index unchanged

Specifying multiple mappings

Give one mapping per group of input indices:

reshape(A, H1 => (H1a, H1b), (H2a, H2b) => H2, H3 => H3)

This splits the first index, combines the next two, and leaves the last unchanged.

Single-mapping shorthand

When only one mapping is given, it is replicated if needed:

  • If it consumes all indices of t, it is applied once:

    reshape(v, H => (H1, H2))        # length-1 vector → 2-index tensor

  • If t has twice as many indices as the mapping consumes, the mapping is applied to the first half and again to the second half. This covers the common case of a square operator matrix, where the first index is the output space and the second is the input space:

    reshape(m, H => (H1, H2))        # matrix → 4-index tensor
# equivalent to reshape(m, H => (H1, H2), H => (H1, H2))

reshape(T, (H1, H2) => H)        # 4-index tensor → matrix
# equivalent to reshape(T, (H1, H2) => H, (H1, H2) => H)

For asymmetric operators, specify both mappings explicitly:

reshape(m, Hout => (H1, H2), Hin => (K1, K2))

Many-to-many mappings are evaluated directly and are equivalent to an explicit combine-then-split composition:

reshape(A, (H1, H2) => (K1, K2))# equivalent to reshape(reshape(A, (H1, H2) => Hmid), Hmid => (K1, K2))

where Hmid is the canonical combined space of the input tuple.

When repeat=true, the single given mapping is applied to every consecutive group of input indices. For example, with a 3-index array where every index lives on H:

reshape(A, H => (H1, H2); repeat=true)# equivalent to reshape(A, H => (H1, H2), H => (H1, H2), H => (H1, H2))

Missing states

Some basis states of the input spaces may have no counterpart in the output spaces, e.g. when splitting into a truncated space or combining into a symmetry-constrained space. By default an ArgumentError is thrown if t has a nonzero entry on such a state, since that amplitude would be lost. Zero entries are fine, so e.g. combining unconstrained spaces into a parity-conserving space works for parity-preserving operators. With skipmissing=true, the components on missing states are silently dropped.

Precomputed form

reshape(mappings...; repeat=false, skipmissing=false)

returns a callable ReshapeMap that precomputes the transitions, and can be applied as op(t) or in place as op(out, t).

FermionicHilbertSpaces._foreach_kron_term — Method
_foreach_kron_term(op, inds, ms, Hs, H, extend_state; phase_factors, skipmissing)

Kernel shared by the dense and sparse generalized matrix kron. Calls op(K1, K2, v) for each output matrix element in H, where v is the product of the selected input elements, the recombination weights and the phase factor. inds supplies one row/column index pair per local matrix. FermionicHilbertSpaces._foreach_partial_trace_term — Method
_foreach_partial_trace_term(op, inds, H, Hsub, complement, mapper, alg; phase_factors)

Kernel of the partial-trace map builders, and of the direct partial trace with SubsystemPartialTraceAlg. Calls op(J1, J2, K1, K2, v) for each contribution, where (J1, J2) indexes the input matrix in H, (K1, K2) the output matrix in Hsub, and v excludes the input matrix element. inds is ignored by SubsystemPartialTraceAlg; FullPartialTraceAlg visits the index pairs in inds. FermionicHilbertSpaces._foreach_partial_transpose_term — Method
_foreach_partial_transpose_term(op, inds, H, Hsub, Hout, splits, mapper_out; phase_factors, skipmissing)

Kernel shared by the direct and the sparse-map implementation. For every index pair (J1, J2) in inds (matrix element |f1⟩⟨f2| of H), split f1 → (a1, b1), f2 → (a2, b2), swap the transposed parts, |a1 b1⟩⟨a2 b2| ↦ |a2 b1⟩⟨a1 b2|, recombine into Hout and call op(J1, J2, K1, K2, v) with the full coefficient v.

FermionicHilbertSpaces.apply_local_operator — Function
apply_local_operator(op, state, space, precomp) -> (newstate, amplitude)

Apply the symbolic operator op to the basis state state of space. FermionicHilbertSpaces.default_subspace_index — Method

FermionicHilbertSpaces.permutation_projector — Method
permutation_projector(H, Hs, perms[, weights[, T]]; normalize=true, sparse=true)

Build a group-averaged projector/operator from permutation operators: P = sum(weights[g] * R_g for g), where R_g permutes the factors Hs according to perms[g]. Without weights, every weight is one.

T is the element type of P. It defaults to Int without weights, and otherwise to the element type of weights. For floating point and complex element types, P is replaced by zero if its largest entry is at most sqrt(eps) times the largest weight, so that a sector absent from H gives an exactly zero P instead of roundoff.

Keywords:

  • normalize: rescale P by conj(tr(P)) / sum(abs2, P), which makes P^2 == P when P is proportional to a projector.
  • sparse: return a SparseMatrixCSC if true, and a Matrix otherwise.

Hs may be either a full partition of H (covering all atomic factors) or a proper subsystem list (covering only a subset of atomic factors). In the subsystem case the projector is first constructed on Hsub = tensor_product(Hs...) and then embedded back into H via embed(Psub, Hsub => H).

The space of Nambu states [f[l] for l in labels; f[l]' for l in labels]. representation gives the particle-hole symmetric BdG matrix, [h Δ; -Δ* -h*] / 2 for op = Σᵢⱼ h[i, j] f[i]' f[j] + (Δ[i, j] f[i]' f[j]' + h.c.) / 2, and only quadratic operators can be represented.

FermionicHilbertSpaces.hilbert_space — Method
hilbert_space(f::SymbolicFermionBasis, labels, ::SingleParticle)

The space spanned by the states $c_n^\dagger |0\rangle$ for the modes f[l], l in labels, suitable for non-interacting systems with fermion number conservation. The matrix representation of a quadratic operator is the single-particle matrix, without any contribution from the identity operator. The space wraps a constrained fermionic space, available through parent, and does not combine with tensor products or partial traces.
