Space and Hamiltonian

@fermions f defines symbolic fermions. hilbert_space(f, labels, constraint) gives a space, and representation(op, H, :dense) its matrix.

using FermionicHilbertSpaces, LinearAlgebra@fermions fN = 4ham = sum(f[n+1]'f[n] + hc for n in 1:N-1) + sum(f[n]'f[n] * f[n+1]'f[n+1] for n in 1:N-1)H = hilbert_space(f, 1:N, NumberConservation())
16-dimensional SectorHilbertSpace
Parent: f[1, 2, 3, 4]
Sectors: [0 (1-dim), 1 (4-dim), 2 (6-dim), 3 (4-dim), 4 (1-dim)]

Spinful fermions

Conserve each species separately with a product of constraints; sectors are labelled by vectors such as [1, 1].

@fermions cHup = hilbert_space(c, [(i, :↑) for i in 1:2])Hdn = hilbert_space(c, [(i, :↓) for i in 1:2])Hσ = tensor_product(Hup, Hdn; constraint = NumberConservation(Hup) * NumberConservation(Hdn))sector([1, 1], Hσ)
4-dimensional ConstrainedSpace
Parent: c[(1, :↑), (2, :↑), (1, :↓), (2, :↓)]

A subregion given as a space must list its modes in the order of the parent space. Here the modes of site 1:

HA1 = hilbert_space(c, [(1, :↑), (1, :↓)])subregion(HA1, Hσ)
4-dimensional ConstrainedSpace
Parent: c[(1, :↑), (1, :↓)]

Free fermions

A quadratic Hamiltonian on a SingleParticle() space is its single-particle matrix h, whose negative eigenvalues sum to the ground-state energy. BdG() includes pairing; see Non-interacting hamiltonians.

using FermionicHilbertSpaces.FreeFermionsh = Hermitian(rand(N, N))Hs = hilbert_space(f, 1:N, SingleParticle())ε = eigvals(Hermitian(representation(sum(f[i]' * h[i, j] * f[j] for i in 1:N, j in 1:N), Hs, :dense)))sum(filter(<(0), ε))
-0.6106642830956194

With pairing, on hilbert_space(f, 1:N, BdG()) the energy is tr(h)/2 - sum(filter(>(0), ε)) for the eigenvalues ε of the BdG matrix.

Large spaces

:lazy gives a matrix-free operator for iterative eigensolvers such as Arpack or KrylovKit, which must be installed separately (the example needs using Arpack).

using ArpackHbig = hilbert_space(f, 1:12, NumberConservation(6))hbig = representation(sum(f[n+1]'f[n] + hc for n in 1:11) + 0.5 * sum(f[n]'f[n] * f[n+1]'f[n+1] for n in 1:11), Hbig, :lazy)real(eigs(hbig; nev=1, which=:SR)[1][1])
