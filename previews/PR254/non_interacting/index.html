Non-interacting hamiltonians

Number conserving non-interacting hamiltonians

A quadratic fermionic hamiltonian with number conservation can be written as

\[H = E\mathbf{1} + \sum_{ij} c_i^\dagger\, h_{ij} c_j.\]

The matrix element between two single particle states with modes $n$ and $m$, i.e. $\ket{n} = c_n^\dagger \ket{0}$, is

\[ \bra{m}H\ket{n} = E\delta_{nm} + h_{nm}.\]

If $H$ is hermitian so is $h$ and $E$ is real, but we don't have to restrict to this case here.

One can manually define the hilbert space using only the single particle states as

using FermionicHilbertSpaces, LinearAlgebra@fermions cN = 2H = hilbert_space(c, 1:N, FermionicHilbertSpaces.SingleParticleState.(1:N))h = rand(ComplexF64, N, N)E = rand(ComplexF64)op = E * I + sum(c[i]' * h[i, j] * c[j] for i in 1:N, j in 1:N)representation(op, H) == h + E * I
true

Often, $h_{nm}$ is of interest because diagonalizing it gives information on the quasiparticles in the system.

Use `SingleParticle` instead

For convenience, hilbert_space(c, 1:N, SingleParticle()) can be used to define the hilbert space which will give only the single particle states, and will remove the contribution of the identity operator when calling representation:

H = hilbert_space(c, 1:N, SingleParticle())representation(op,H) == h # true

See Free fermions on a 2D grid for an example of how to use this.

Non-interacting hamiltonians without number conservation

A general non-interacting hermitian operator respecting super-selection can be written as

\[H = E\mathbf{1} + \sum_{ij} \left(c_i^\dagger\, h_{ij} c_j + \frac{1}{2}\left(\Delta_{ij} c_i^\dagger c_j^\dagger + \Delta^*_{ij} c_j c_i\right)\right),\]

where $h$ is hermitian, $E$ is real and $\Delta$ is antisymmetric. We can do something similar as above by doubling the single particle states with the Nambu states $\Psi_n = c_n$ for $n \leq N$ and $\Psi_{n+N} = c_n^\dagger$, where $N$ is the number of fermions. Then the hamiltonian can be written as

\[H = E'\mathbf{1} + \sum_{ij} \Psi_i^\dagger\, M_{ij} \Psi_j.\]

Since we introduced a redundancy by doubling the single particle states, $M$ is not unique. Requiring the particle-hole symmetry $M = -\tau_x M^T \tau_x$ fixes it to

\[M = \frac{1}{2}\begin{pmatrix} h & \Delta \ -\Delta^* & -h^* \end{pmatrix}, \quad E' = E + \frac{1}{2}\mathrm{tr}\, h.\]

The same symmetrization gives a unique $M$ for any quadratic operator, also non-hermitian ones, and then $[H, \Psi_i] = -2 (M\Psi)_i$. We can get this representation manually as follows:

using FermionicHilbertSpaces, LinearAlgebraN = 2states = vec([FermionicHilbertSpaces.NambuState(n, hole) for (n, hole) in Base.product(1:N, (true, false))])@fermions cH = hilbert_space(c, 1:N, states)h = Hermitian(rand(N, N))Δ = rand(N, N) |> m -> m - transpose(m)E = rand()op = E * I + sum(c[i]' * h[i, j] * c[j] + (Δ[i, j] * c[i]' * c[j]' + conj(Δ[i, j]) * c[j] * c[i]) / 2 for i in 1:N, j in 1:N)M = representation(op, H) |> FermionicHilbertSpaces.normal_order_to_bdgM ≈ [h Δ; -conj(Δ) -conj(h)] / 2
true

The matrix returned by representation on this space depends on the ordering of operators in the symbolic operator op, and FermionicHilbertSpaces.normal_order_to_bdg converts it to the particle-hole symmetric choice above.

Use `BdG` instead

By defining the hilbert space with hilbert_space(c, 1:N, BdG()), one automatically gets the Nambu states and representation will return $M$ without the need to manually convert it:

Hbdg = hilbert_space(c, 1:N, BdG())representation(op, Hbdg) ≈ M # true

The BdG space wraps the constrained space above, available through parent, and does not combine with tensor products or partial traces.

Quasiparticles

eigen(A, FermionicHilbertSpaces.BdGEigen()) diagonalizes a BdG matrix while keeping the particle-hole pairing of its eigenvectors. The eigenvalues are sorted, so for N modes columns k and 2N + 1 - k are partners with eigenvalues e and -e whose quasiparticles are adjoints of each other. A column [u; v] gives the quasiparticle $\gamma^\dagger = \sum_i u_i c_i^\dagger + v_i c_i$, which raises the energy by $2e$. The matrix must be Hermitian, and eigenvalues with abs(e) <= cutoff * maximum(abs, vals) are set to zero, with the default cutoff = 2N * eps as for rank.

using FermionicHilbertSpaces: BdGEigenHbdg = hilbert_space(c, 1:N, BdG())vals, vecs = eigen(representation(op, Hbdg, :dense), BdGEigen())vals

Expectation values

On the single-particle and BdG spaces, expectation(op, G, H) takes the correlation matrix of the state: $G_{ij} = \langle c_i^\dagger c_j \rangle$ on the single-particle space and $G_{ij} = \langle \Psi_i^\dagger \Psi_j \rangle$ on the BdG space. The operator must be quadratic, and its identity part is included. For a thermal state of the single-particle hamiltonian h, $G = (1 + e^{\beta h})^{-T}$:

using FermionicHilbertSpaces, LinearAlgebra@fermions cH = hilbert_space(c, 1:4, SingleParticle())ham = sum(c[n]' * c[n+1] + hc for n in 1:3) + 1h = representation(ham, H, :dense)G = transpose(inv(I + exp(10 * h)))expectation(ham, G, H)
-1.2335146369152592

From matrices and eigenvectors back to symbolic operators

quadratic_operator(M, H) turns a matrix on a BdG or SingleParticle space back into a symbolic operator, and quasiparticle(v, H) turns an eigenvector into the operator that creates the corresponding quasiparticle. On the BdG space, quadratic_operator returns the traceless operator, which differs from the original one by a constant.

using FermionicHilbertSpaces, LinearAlgebrausing FermionicHilbertSpaces: BdGEigen, quasiparticle, quadratic_operator@fermions cH = hilbert_space(c, 1:2, BdG())M = representation(c[1]' * c[2] + c[1]' * c[2]' + hc, H, :dense)vals, vecs = eigen(M, BdGEigen())quadratic_operator(M, H), quasiparticle(vecs[:, end], H)
(-c[1]*c[2] + c†[1]*c[2] + c†[1]*c†[2] + c†[2]*c[1], -0.5000000000000001*c[1] + 0.4999999999999998*c†[2] + 0.49999999999999994*c†[1] + 0.5000000000000003*c[2])
