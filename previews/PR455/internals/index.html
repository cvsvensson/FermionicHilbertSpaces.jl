Base.reshape — Method
reshape(t, mappings...; repeat=false, projection=false, alg)

Reshape the array t by splitting or combining its indices according to Hilbert-space mappings. The mappings are applied left to right, each one consuming the next consecutive group of input indices. Each mapping reads input => output; see Pair arguments.

Mapping forms

H => (H1, H2, ...)   split one index into several(H1, H2, ...) => H   combine several consecutive indices into one(H1, H2, ...) => (K1, K2, ...)  repartition several indices into severalH => H               leave one index unchanged

Specifying multiple mappings

Give one mapping per group of input indices:

reshape(A, H1 => (H1a, H1b), (H2a, H2b) => H2, H3 => H3)

This splits the first index, combines the next two, and leaves the last unchanged.

Single-mapping shorthand

When only one mapping is given, it is replicated if needed:

  • If it consumes all indices of t, it is applied once:

    reshape(v, H => (H1, H2))        # length-1 vector → 2-index tensor

  • If t has twice as many indices as the mapping consumes, the mapping is applied to the first half and again to the second half. This covers the common case of a square operator matrix, where the first index is the output space and the second is the input space:

    reshape(m, H => (H1, H2))        # matrix → 4-index tensor
# equivalent to reshape(m, H => (H1, H2), H => (H1, H2))

reshape(T, (H1, H2) => H)        # 4-index tensor → matrix
# equivalent to reshape(T, (H1, H2) => H, (H1, H2) => H)

For asymmetric operators, specify both mappings explicitly:

reshape(m, Hout => (H1, H2), Hin => (K1, K2))

Many-to-many mappings are evaluated directly and are equivalent to an explicit combine-then-split composition:

reshape(A, (H1, H2) => (K1, K2))# equivalent to reshape(reshape(A, (H1, H2) => Hmid), Hmid => (K1, K2))

where Hmid is the canonical combined space of the input tuple.

When repeat=true, the single given mapping is applied to every consecutive group of input indices. For example, with a 3-index array where every index lives on H:

reshape(A, H => (H1, H2); repeat=true)# equivalent to reshape(A, H => (H1, H2), H => (H1, H2), H => (H1, H2))

Missing states

Some basis states of the input spaces may have no counterpart in the output spaces, e.g. when splitting into a truncated space or combining into a symmetry-constrained space. By default an ArgumentError is thrown if t has a nonzero entry on such a state, since that amplitude would be lost. Zero entries are fine, so e.g. combining unconstrained spaces into a parity-conserving space works for parity-preserving operators. With projection=true, the components on missing states are silently dropped.

With alg = NoScalarIndexingAlg(), the default for dense GPU arrays, t is reshaped by array indexing and broadcasting only.

Precomputed form

reshape(mappings...; repeat=false, projection=false)

returns a callable ReshapeMap that precomputes the transitions, and can be applied as op(t) or in place as op(out, t).

FermionicHilbertSpaces._foreach_kron_term — Method
_foreach_kron_term(op, inds, ms, Hs, H, extend_state; phase_factors, projection)

Kernel shared by the dense and sparse generalized matrix kron. Calls op(K1, K2, v) for each output matrix element in H, where v is the product of the selected input elements, the recombination weights and the phase factor. inds supplies one row/column index pair per local matrix. Terms whose column state is not in H are skipped. When projection=false, a nonzero term from a state of H to a state that is not in H throws ArgumentError.

FermionicHilbertSpaces._foreach_partial_trace_term — Method
_foreach_partial_trace_term(op, inds, H, Hsub, complement, mapper, alg; phase_factors)

Kernel of the partial-trace map builders, and of the direct partial trace with SubsystemPartialTraceAlg. Calls op(J1, J2, K1, K2, v) for each contribution, where (J1, J2) indexes the input matrix in H, (K1, K2) the output matrix in Hsub, and v excludes the input matrix element. inds is ignored by SubsystemPartialTraceAlg; FullPartialTraceAlg visits the index pairs in inds. States that are not in H or Hsub are skipped.

FermionicHilbertSpaces._foreach_partial_transpose_term — Method
_foreach_partial_transpose_term(op, inds, H, Hsub, Hout, splits, mapper_out; phase_factors, projection)

Kernel shared by the direct and the sparse-map implementation. For every index pair (J1, J2) in inds (matrix element |f1⟩⟨f2| of H), split f1 → (a1, b1), f2 → (a2, b2), swap the transposed parts, |a1 b1⟩⟨a2 b2| ↦ |a2 b1⟩⟨a1 b2|, recombine into Hout and call op(J1, J2, K1, K2, v) with the full coefficient v.

FermionicHilbertSpaces.apply_local_operator — Function
apply_local_operator(op, state, space, precomp) -> (newstate, amplitude)

Apply the symbolic operator op to the basis state state of space. Returns the new state and its amplitude; an amplitude of zero means that op annihilates state. space is the group that op acts on, so it can be used for dispatch. precomp is the value of _precomputation_before_operator_application for op and space.

This is the method that connects a custom operator type to matrix representations, partial traces and the other operations on spaces.

Name of an atom: the key that identifies its degrees of freedom. FermionicHilbertSpaces.basis_transformation — Method
basis_transformation(Hfrom, Hto)

Return (U, dropped), the basis change U from Hfrom to Hto and the dropped states.

U is the sparse dim(Hto) × dim(Hfrom) matrix with U[i, j] = 1 if basis state j of Hfrom is basis state i of Hto, and dropped are the indices of the states of Hfrom that do not exist in Hto. States of Hto that do not exist in Hfrom give zero rows. Hfrom and Hto must have the same atoms (see match_same_atoms), but their groups may come in different orders.

FermionicHilbertSpaces.change_basis — Method
change_basis(m, Hfrom => Hto; projection=false, alg)
change_basis(m, Hfrom, Hto; projection=false, alg)

Express m in the basis of Hto, where Hfrom and Hto have the same atoms but possibly different (or differently ordered) basis states. Unless projection=true, throws an ArgumentError if m has nonzero elements involving states of Hfrom that are not in Hto.

Either side can be an Axes, one space per axis of m: change_basis(m, H => Axes(Hout, Hin)) extracts the block of m with rows on Hout and columns on Hin, and change_basis(blk, Axes(Hout, Hin) => H) places it in a matrix on H that is zero elsewhere.

A vector or matrix m can be a dense GPU array, for which alg defaults to NoScalarIndexingAlg.

FermionicHilbertSpaces.default_subspace_index — Method
default_subspace_index(constraint, parent, states)

Build the index (see state_position) of the subspace of parent with basis states, in order. constraint is the constraint that selected states: the one given to hilbert_space, constrain_space, tensor_product or sector, or for a tensor_product of sector spaces without a new constraint, the one built from the constraints of the factors. FermionicHilbertSpaces.highest_weight_states — Method
highest_weight_states(H, raisers; basis = Returns(I), check = true)

Return a dictionary from sector labels of H to the states in that sector annihilated by all raisers. For spins, with H = hilbert_space(S, 1:N, Sz) and Splus = sum(S[k][:+] for k in 1:N), the key is the total spin J and the columns of highest_weight_states(H, Splus)[J] are an orthonormal basis, in sector(J, H), of the states |J, J⟩, one per multiplet. With other labels the key is the label of the highest-weight sector, e.g. [Nup, Ndn] for spinful fermions or [n1, n2, n3] for SU(3). Several raisers go in a vector; a raiser may be an operator or its matrix on H.

  • The sectors must be labelled by the eigenvalues of the symmetry's diagonal generators (Sz for spins, each flavour number for SU(N)); extra labels are fine.
  • Total spin J at Sz = M needs the sectors from M up to the top, e.g. Sz => M:N//2, or Sz => 0:N//2 for every J at M ≥ 0; otherwise representation throws.

basis(M) restricts the search to the span of orthonormal columns in sector(M, H), e.g. a momentum sector from symmetric_sector; the results stay in sector(M, H) coordinates.

check verifies the commutator conditions and that each basis(M) is orthonormal, and can be turned off. The results block-diagonalize a Hamiltonian only if it commutes with the raisers, which is not checked.

FermionicHilbertSpaces.internal_rep — Method
internal_rep(state, space, ::Type{Int}) -> Int
physical_rep(n::Int, ::Type{B}) -> B

Convert a basis state of type B to an integer and back, with physical_rep(internal_rep(state, space, Int), B) == state. When every group of a product space has these methods, operators on the product space act on the integers instead of on the states. Without them, the product space uses the states directly, which is slower. A product with a fermionic group of 63 or more modes uses a wider signed integer type in place of Int, so methods for any T<:Integer keep the integer path there.

FermionicHilbertSpaces.permutation_projector — Method
permutation_projector(H, Hs, perms[, weights[, T]]; normalize=true, sparse=true, phase_factors=true)

Build a group-averaged projector/operator from permutation operators: P = sum(weights[g] * R_g for g), where R_g permutes the factors Hs according to perms[g]. Without weights, every weight is one.

T is the element type of P. It defaults to Int without weights, and otherwise to the element type of weights. For floating point and complex element types, P is replaced by zero if its largest entry is at most sqrt(eps) times the largest weight, so that a sector absent from H gives an exactly zero P instead of roundoff.

Keywords:

  • normalize: rescale P by conj(tr(P)) / sum(abs2, P), which makes P^2 == P when P is proportional to a projector.
  • sparse: return a SparseMatrixCSC if true, and a Matrix otherwise.
  • phase_factors: include the fermionic signs of the permutations, as in permutation_operator.

Hs may be either a full partition of H (covering all atomic factors) or a proper subsystem list (covering only a subset of atomic factors). In the subsystem case the projector is first constructed on Hsub = tensor_product(Hs...) and then embedded back into H via embed(Psub, Hsub => H).
